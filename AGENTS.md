Этот файл читают нейросети (ChatGPT / Codex, Claude, Copilot и др.), которые подключаются к разработке. Прочитай его целиком перед первой правкой.

## Проект
- **ТЕРРА — Последний человек · 2136.** Браузерный 3D-сурвайвал: экспедиция «Арес-7» возвращается с Марса, капсула «ТЕРРА-1» садится в заросшие руины России.
- Текущая версия: **v0.4.19 «Детали мира»** (ранний доступ).
- Сайт: https://ckupkakhv-droid.github.io/terra-2136/ · Игра: https://ckupkakhv-droid.github.io/terra-2136/play/

## Устройство репозитория
- `index.html` — лёгкая витрина (лендинг). Игру НЕ загружает.
- `play/index.html` — игровой бандл (esbuild), Three.js r160, fflate и PeerJS. Модели, текстуры и звук лежат в `play/assets/pack/`; асинхронный `play/assets/boot.js` проверяет архив до запуска игры. Самостоятельный HTML создаёт `scripts/build-offline.py`.
- `assets/` — скриншоты и медиа для витрины и README.
- `README.md`, `CHANGELOG.md`, `LICENSE`, `.github/ISSUE_TEMPLATE/`.
- Сборки не нужно собирать: GitHub Pages раздаёт файлы как есть.

## Ограничения
- Лимит GitHub — 100 МБ на файл, предупреждение с 50 МБ. Не вшивай новые крупные ассеты в игровой HTML: клади их в `play/assets/`. Офлайн-сборщик сохраняет потолок 50 МБ; целевой размер — до 40 МБ.
- Формат сохранений — profile v3. Не ломай совместимость сохранений без явного решения и записи в CHANGELOG.
- Лицензия: все права защищены (© 2026 Команда «Терры»). Не добавляй open-source лицензию и чужие ассеты без указания автора и лицензии в README → «Благодарности».

## Как работать
1. Не пушь напрямую в `main`. Создавай ветку `feature/<кратко>` или `fix/<кратко>`.
2. Открывай pull request с описанием на русском: что изменено, как проверить, есть ли риск для сохранений.
3. Каждое изменение для игроков — строка в `CHANGELOG.md` (раздел «Не выпущено»).
4. Проверка: `python3 -m http.server 8080` → открыть http://localhost:8080/play/ в Chrome, консоль без ошибок, меню и «Новая игра» работают.
5. Если доступны исходники по модулям — коммить их в `src/` вместе со сборкой, чтобы правки были читаемыми.
