# Цельные валуны

`qn_rock_medium_1` и `qn_rock_medium_3` заменяют меши с разорванной поверхностью. Полные исходники — `Rock_1.gltf` и `Rock_3.gltf` из Quaternius LowPoly Nature Pack, **CC0 1.0**. Автор — [Quaternius](https://quaternius.com). Источники получены из [flo-bit/tiny-planets](https://github.com/flo-bit/tiny-planets/tree/b51aa232dff0799908eb97927381bb33f40cf2d6/public/lowpoly_nature); коммит, Git blob, SHA256 и размеры закреплены в [source-lock.json](source-lock.json).

Копия [лицензии](LICENSE_Quaternius.txt) взята из [набора Quaternius](https://github.com/Rumpunzel/Strongerholder/blob/b449e3856d6ccafef2d59276729e45f0c5cb12e5/3d_prototype/quaternius/Ultimate%20Nature%20Pack/License.txt), как и для [деревьев](../nature/README.md). Исходные glTF содержат встроенные буферы; дополнительных текстур и скачивания LFS не требуется. Лицензия самой «Терры» прежняя.

## Сборка

Проверена Blender **4.3.2**:

```sh
blender -b --python-exit-code 1 --python tools/art/rocks/build_meshes.py -- --output /tmp/terra-rocks
python3 tools/art/rocks/install_pack.py /tmp/terra-rocks/entries.json
python3 tests/rocks-topology.py
python3 tests/nature-topology.py
python3 scripts/build-offline.py
```

Сборщик проверяет исходные хеши и замкнутость, запекает преобразования и сваривает вершины. Два прохода сглаживания соседних вершин смягчают ступенчатую форму старого набора; асимметрия сохраняется. Подгонка использует прежние габариты из [native-layout.json](native-layout.json), основание остаётся на нуле. Длинные резкие рёбра получают небольшие фаски. При необходимости применяется связное упрощение `COLLAPSE`; бюджет каждого меша ограничен прежним числом треугольников.

Перед упаковкой вершины приводятся к сетке `int16`, микрограни очищаются, нормали пересчитываются. Проверяется именно окончательная квантованная сетка. Готовые варианты имеют **186 и 210** треугольников вместо **260 и 260**. В выходном каталоге лежат GLB для осмотра и `entries.json` для установки. GLB не нужно копировать в `play/assets`, чтобы не удвоить ассеты в самостоятельном HTML.

Рантайм использует прежний формат — 24 байта на треугольник. Материал Rock030, случайная расстановка, заглубление, коллизии и код взаимодействий прежние. Установщик сохраняет байты **100 остальных пропсов**, обновляет смещения, gzip с фиксированным временем, манифест и его контрольную сумму в HTML. Повторная сборка и установка воспроизводят архив точно.

`tests/rocks-topology.py` сравнивает данные с опубликованной 0.4.25: оба новых меша замкнуты после квантования, нормали/габариты/бюджеты и исходные хеши верны, остальные записи совпадают побайтово. Историческая проверка деревьев отдельно учитывает эти два заменённых валуна.

Для браузерного сравнения раздавайте самостоятельный HTML опубликованной 0.4.25 по отдельному адресу:

```sh
TERRA_BASELINE_URL=http://127.0.0.1:8182/terra-v25.html TERRA_TEST_URL=http://127.0.0.1:8180/play/ python3 tests/rocks-scene.py
```

Тест проверяет метаданные девяти районов, штатный выбор всех трёх видов камней, коллизии/генератор, материалы, посадку и лучи с восьми направлений. [Кадры и результаты](../../../docs/art/rocks-0426/README.md).
