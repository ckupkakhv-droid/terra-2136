# Цельные деревья

18 игровых вариантов используют 15 полных glTF-источников Quaternius LowPoly Nature Pack: пять лиственных деревьев, пять сосен и пять сухих деревьев. Ещё три искривлённых варианта получены плавным изгибом и закручиванием сухостоя.

Автор исходных моделей — [Quaternius](https://quaternius.com), **CC0 1.0**. [Текст лицензии](LICENSE_Quaternius.txt) сохранён из [копии набора Quaternius](https://github.com/Rumpunzel/Strongerholder/blob/b449e3856d6ccafef2d59276729e45f0c5cb12e5/3d_prototype/quaternius/Ultimate%20Nature%20Pack/License.txt). Источники glTF получены из [flo-bit/tiny-planets](https://github.com/flo-bit/tiny-planets/tree/b51aa232dff0799908eb97927381bb33f40cf2d6/public/lowpoly_nature); версия, Git blob, SHA256 и размер каждого файла закреплены в [source-lock.json](source-lock.json). Файлы содержат встроенные буферы, загрузка внешних текстур не требуется. Лицензия проекта «Терра» остаётся прежней.

## Сборка

Проверена **Blender 4.3.2** и Python 3 со стандартной библиотекой:

```sh
blender -b --python-exit-code 1 --python tools/art/nature/build_meshes.py -- --output /tmp/terra-nature
python3 tools/art/nature/install_pack.py /tmp/terra-nature/entries.json
python3 tests/nature-topology.py
python3 scripts/build-offline.py
```

`--python-exit-code 1` обязателен для обнаружения ошибок фонового Blender. В начале сборки удаляется прежний `entries.json`; новый появляется после успешной обработки всего набора.

Сборщик запекает преобразования glTF, совмещает основание ствола с игровым центром и подгоняет высоту/горизонтальные пределы к [native-layout.json](native-layout.json). Эта таблица сохраняет прежние имена, габариты, точность упаковки, палитру и верхнюю границу числа треугольников. Крона помещается также в круг штатного скрытия срубленного дерева; запас учитывает движение от ветра. Положения объектов и правила добычи берутся из прежнего игрового кода.

Упрощение `COLLAPSE` сохраняет замкнутую поверхность. Часть бюджета отводится фаскам длинных рёбер древесины; при превышении бюджета сборщик повторяет упрощение из полного исходника. Основания сосен сужены, чтобы убрать массивные угловатые формы. Перед окончательной проверкой вершины приводятся к реальной сетке `int16`: схлопнувшиеся микрограни фасок удаляются с сохранением замкнутости. Проверки выполняются после этого шага.

В каталоге вывода создаются GLB для осмотра и компактные записи `entries.json`. GLB можно проверить и подготовить обычными glTF-инструментами, например:

```sh
npx --yes @gltf-transform/cli@4.2.1 dedup /tmp/terra-nature/qn_commontree_1.glb /tmp/terra-nature/qn_commontree_1-review.glb
```

В игру поступает прежний формат пропсов: 24 байта на треугольник — квантованные позиции, нормаль и цвет. Он сохраняет общие пакеты отрисовки, ветер и нативную модель падающего дерева. GLB для ревью не нужно копировать в `play/assets`: самостоятельный сборщик включил бы их повторно.

`install_pack.py` сохраняет байты остальных 84 пропсов, обновляет смещения записей, контрольную сумму архива, манифест и его ссылку в загрузчике. Проверка `nature-topology.py` независимо читает упакованные треугольники и сравнивает их с выпущенной 0.4.22: замкнутая древесина, направление нормалей, корни, габариты, радиус рубки, бюджет и неизменность остальных пропсов.

Браузерная проверка:

```sh
TERRA_BASELINE_URL=http://127.0.0.1:8181/terra-v22.html TERRA_TEST_URL=http://127.0.0.1:8180/play/ python3 tests/nature-scene.py
```

По первому адресу должен раздаваться самостоятельный HTML выпущенной 0.4.22. Тест проверяет его идентичность по числу треугольников контрольной модели, сравнивает метаданные/ГСЧ девяти районов и показывает все 18 моделей в одной сцене. [Кадры и результаты](../../../docs/art/nature-0423/README.md).
