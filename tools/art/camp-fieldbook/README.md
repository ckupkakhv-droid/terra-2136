# Материалы полевого альбома

Собственные игровые материалы Команды «Терры», созданы с OpenAI Image Generation 6 ноября 2026 года по художественному направлению владельца: потёртая бумага, тёмная кожа, латунь, синие чертежи, фотографии вымышленных выживших. Изображения референсов не включены в игру.

Три исходных атласа: четыре плоских материала без надписей; восемь вымышленных портретов без рамок; четыре белых инженерных иллюстрации на прозрачном фоне (лесопилка, генератор, насос, вышка). Имена, профессии, цифры, цены, состояния и команды рисует интерфейс из настоящих данных. Готовые растровые экраны с фиктивными числами не используются.

Оптимизированные ресурсы: `play/assets/ui/camp/`. Материалы 512 × 512, восемь портретов по 256 × 256, чертежи 520 × 400 RGBA. Только разрешение, кадрирование по прозрачным промежуткам и сжатие WebP; соседние иллюстрации не попадают в кадр.

`prepare.py --materials <png> --portraits <png> --blueprints <png>` повторяет упаковку при наличии исходных атласов. Их имена и SHA256, контрольные суммы экспортов — в `provenance.json`. Исходные PNG генерации сохранены в рабочем каталоге `/workspace/generated_images`; в игровой пакет входят только WebP.

Исходная геометрия объектов, персонажи мира и их анимации этим набором не заменяются. Личные дела используют имеющийся персональный портрет, если он есть; сгенерированный атлас — постоянный визуальный вариант для карточек без него. Новых персональных данных в сохранение не добавляется.
