# Киоск «ХЛЕБ»

Собственная процедурная геометрия команды «Терры» вместо повреждённого `TERRA_KIT.decor.kiosk`. Стальной каркас, утопленные листы, открытые окна, прилавок, пол и полка, дверь, наклонная кровля и выцветшая вывеска. Кириллица собрана из собственных прямых штрихов, без зависимости от шрифтов. Все права на новую геометрию защищены.

Текстуры **не созданы заново**: используются неизменённые карты существующего атласа `decor` из набора игры. `palette.json` закрепляет небольшие участки металла, краски и ржавчины, включая лист старого электрошкафа. Исходные сведения о сторонних наборах остаются в README проекта. Новых сторонних ресурсов нет.

## Воспроизведение

Из корня репозитория, Python 3, только стандартная библиотека:

```sh
python3 tools/art/kiosk/generate.py /tmp/terra-kiosk-generated.json
python3 tools/art/kiosk/install_pack.py /tmp/terra-kiosk-generated.json
python3 tests/kiosk-topology.py
```

`native-layout.json` закрепляет габариты и хеши карт опубликованной 0.4.34. Генератор отказывается работать с другим атласом. Необязательный `select_palette.py` использует NumPy/Pillow для изучения старого атласа; для повторной сборки он не нужен.

| LOD | Старые треугольники | Новые треугольники | Упакованные вершины |
| --- | ---: | ---: | ---: |
| Ближний | 2599 | 1159 | 2009 |
| Средний | 1167 | 568 | 1076 |
| Дальний | 340 | 262 | 524 |

Крыша упрощается с восьми волн до четырёх и плоского листа. Вдали исчезают фаски и мелкие крепления, но сохраняются оконные проёмы, вывеска, пол и полка. Дальние тонкие листы имеют две противоположные стороны; это намеренная открытая поверхность, а не разрыв каркаса. Остатки стекла и краска тоже не требуют замкнутого объёма.

Габариты `w/h/d` прежние; все LOD вписаны в точные границы прежнего ближнего меша. Основание каждого — `y=0`, верх — `3,5 м`. Штатная расстановка, вращение, масштаб, заглубление и коллизии не редактируются.

Установщик заменяет три блока внутри нативного массива, удаляет прежние данные и переносит указатели остальных моделей. Сверяет их атрибуты побайтно, сохраняет карты и остальные группы, обновляет опись и закреплённый в HTML хеш. Повторная установка не меняет результат. Сварка совпадающих полных вершин сохраняет жёсткие рёбра и границы UV. Штатные материал и пакет отрисовки остаются общими.

`tests/kiosk-scene.py` сравнивает опубликованную 0.4.34 с рабочей сборкой через реальный загрузчик и рендерер. Для проверки самостоятельного HTML задайте `TERRA_TEST_URL=http://127.0.0.1:8180/terra.html` и путь `TERRA_BASELINE_FILE` к SHA-проверенному офлайн-файлу 0.4.34. Проверки и ограничения измерений описаны в `docs/art/kiosk-0435/README.md`.
