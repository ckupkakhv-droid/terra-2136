# Насос I

Собственный аварийный агрегат для одной камеры Южного коллектора. Кожух со срезанными углами, патрубки с фланцами, вентиль, манометр, анкеры и жёлтая табличка. Надпись «НАСОС I» собрана из прямых штрихов. Файла шрифта, чужой модели и новой текстуры нет.

В игре меш рисуется тем же статическим материалом, что бетон коллектора: вершинный цвет, идентификатор поверхности и уже подключённые карты грязи. Отдельного света нет.

Габарит не выходит за прежний ящик `1,4 × 1,56 × 1,2` м (низ на `y=0,2`). Коллизия не добавляется. Насос II остаётся старым примитивом.

## Сборка

```sh
python3 tools/art/sewer_pump/pump_gen.py
```

Нужны NumPy и gltfpack 1.3 (`GLTFPACK` или `/tmp/terra-gltfpack`). Упаковка: `EXT_meshopt_compression` и `KHR_mesh_quantization`.

| LOD | Треугольники | Что остаётся |
| --- | ---: | --- |
| lod0 | 774 | кожух, патрубки, вентиль, манометр, рёбра, табличка с надписью |
| lod1 | 483 | кожух, патрубки, вентиль, табличка с надписью |
| lod2 | 158 | кожух, мотор, труба, жёлтая табличка без букв |

Предел ближнего LOD — 2000 треугольников. Переключение в игре по расстоянию камеры: 34 м и 52 м (`play/ui/sewer-pump.js`).
