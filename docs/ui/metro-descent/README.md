# Метро · настоящий спуск · v0.4.18

`station-desktop.jpg` (1280×800) и `station-portrait.jpg` (390×844) — кадры работающей игры, снятые `tests/metro-ground.py` в Chromium/SwiftShader с низким качеством и сенсорными кнопками. Изображения только преобразованы в JPEG.

Станция (90, 82): проём 4,8×5,6 м, 16 ступеней по 0,15 м, глубина 2,4 м. Коллизии стен, исходная точка входа и быстрый переход сохранены. Профиль ходьбы находится в штатном кэше чанка и удаляется вместе с ним; сохранения profile v3 не меняются.

Проверки: лучи через отверстие и все ступени на двух станциях; WASD вниз/вверх; E с нижней площадки, вход и возврат; отказ меню глубины вне шахты; удаление/пересоздание кэша. Сравниваются исходные метаданные, ГСЧ и границы трёх чанков. Защитные сценарии: край чанка, вода, чужое основание, позднее пересечение и подвал. Отдельный `tests/metro-entrance.py` проверяет камеру, отмену и совместимость коллектора.

При проверках перехода постобработка временно заменена счётчиком/пустой функцией; геометрия поверхности и ходьба сняты настоящим рендерером. Физический телефон и запуск через file:// не проверены.
