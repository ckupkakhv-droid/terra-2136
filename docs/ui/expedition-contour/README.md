# Экспедиционный контур

Пилот оформления: HUD, главное меню и обложка лагеря. Альбом, команды, цены и profile v3 прежние. Кадры сняты в headless Chromium со SwiftShader с одной и той же локальной игры, не с макета.

## Что означают цифры макета

Сверка с обновлением HUD и снабжения, без новых подписей.

| В макете | В игре |
| --- | --- |
| Уровень «1» | `#lvl`. Открывает навыки. |
| «100 / 100» и красная полоса | Здоровье, `#hpt`. |
| Тонкая золотая полоса | Выносливость, `#stb`. Числа на полосе нет. |
| Холодная полоса ниже | Опыт до следующего уровня, `#xpb`. |
| Две «100» | Еда и вода игрока. Это не склад лагеря и не пара «из максимума». |
| «1д · 08:30» | День и время, `#clock`. |
| Четыре нуля и «0/24» | Лом, дерево, химия, ткань и оружие в рюкзаке относительно предела. |
| «Цель» | Уже существующее раскрытие `#obj`. Текст цели живой. |
| Кружок у миникарты | `#evPulse`, пульс зоны. Новой кнопки нет. |
| «Зона крушения» | `#zone`. Рядом счётчик убийств `#kills`, не отдельный «+0» макета. |
| Лагерь, карта, пауза | `#bCamp`, `#bMap`, `#bPause`. |
| Граната и оружие | `#throwBox` и `#weap`. Имя, число и «кулаки» пишет игра. На сенсорном экране бросок остаётся на своей кнопке. |
| Еда «6 / 8», вода «6 / 8» | Склад лагеря: запас / резерв. Кнопка «Распределить · 0» штатная. |
| «Ⅱ» | Кнопка пояснения паузы альбома. Видимый текст теперь «Пауза», длинное пояснение на месте. |
| Экран навыков «Нет данных» | Не делался: в макете нет данных, которые можно честно показать. |

## Что изменилось

HUD стал плотным полевым планшетом: тёмный мат, охра, прежние цвета здоровья, выносливости, опыта, радиации, еды и воды. На портрете карта и кнопки «Лагерь / Карта / Пауза» стоят столбиком и не накрывают зону. На низком альбомном экране зона и счётчик убийств уходят в центр, ниже цели: справа их закрывали сенсорные команды.

В главном меню «Новая игра» — основная кнопка, пока нет продолжения. «Продолжить», «Настройки» и «Управление» остаются с полными подписями. Четыре уже существующие команды резерва и записи собраны в «Резерв и запись». Список закрыт, пока его не откроют; открытие не пишется в сохранение. Тексты команд и их обработчики прежние.

Обложка лагеря осталась альбомом. У отключённого «Распределить» видна штатная причина. На пустом лагере это «Нет свободных отдохнувших жителей». «Резерв · i» по-прежнему раскрывает справку.

## Проверка

`tests/expedition-contour.py`, один прогон, окна 1440×900, 390×844, 844×390, 320×568 и 360×640. Уменьшенное движение: длительность перехода логотипа и полосы здоровья `0s`.

На старте у капсулы: здоровье `100 / 100`, еда `100`, вода `100`, рюкзак `0/24`, цель «Выберитесь из капсулы», зона «Зона крушения», оружие «Без оружия», «кулаки». Позже игра может подобрать палку сама: это уже мир, не подмена подписи.

Клавиатура: Enter открывает лагерь, Tab уходит на следующий контроль альбома, Space открывает пояснение паузы, Esc закрывает пояснение и затем альбом, фокус возвращается на «Лагерь». Состояние снова `play`.

Пути ключей `terra_save` до и после этих действий совпали. Ключей с именем контура локальное хранилище не получало. Ошибок JavaScript не было.

## Не проверено

Safari, живые телефоны и вырез экрана. Отступы по-прежнему берутся из `env(safe-area-inset-*)`, но headless Chrome этот вырез не подставлял. Полный бой, метро и `file://` не гонялись. Экран мастерства оружия из макета не добавлялся.
