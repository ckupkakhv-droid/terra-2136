# Канализация: первый игровой участок

Основа: main 14154b0. Вход в Южный коллектор: 12, −10, отмечен люком и штатным значком входа на мировой карте. На карте есть кнопка подземного слоя. Спуск только у входа, карта не телепортирует игрока.

## Реализовано

Семь соединённых секторов, трубы, бетонные обходы, водяной канал, насосные станции и лестница обратно. В исследуемых секторах появляются обычные заражённые. Бетонные обходы остаются сухими, замедляет центральный канал. Два насоса снимают затопление: используется штатное замедление подземелий. Насосы и обнаруженные записи действуют до конца вылазки, после нового спуска сбрасываются. Контейнеры используют существующее сохранение подземелий; новый формат сейва не вводится. Для защиты переходов внутренний theme остаётся metro, а отдельная геометрия выбирается только по seed этого входа.

Записи о событиях AGI, Ambrala, Рафаэле и направлении к Москве — художественные материалы кампании. Они не изменяют автоматически текущий этап основной истории и не утверждают реальные исторические события. Записи открываются по мере исследования.

## Следующий этап, ещё не реализован

Рафаэль: последний из зелёного клана, потерявший братьев и учителя в сражении при AGI; мрачный охотник, связанный с крысами, с двумя саями. Сейчас присутствует только сюжетная запись: персонажа, боя, анимаций и катсцены нет. Существующий босс не выдаётся за новую модель. Нужны согласованный ассет, анимации, боевая телеграфия и постановочная камера с пропуском сцены/уменьшенной анимацией.

Уникальная высокая награда потребует отдельной защищённой транзакции: UID предмета, право выдачи, подтверждённое сохранение победы, отсутствие повторной выдачи при загрузке, совместимость старых предметов. До проверки этой цепочки награда не начисляется. Предлагаемый предмет — парные саи с самостоятельным поведением, а не переименованная катана.

Размещение существующих моделей крыс, дополнительные коллекторы и межрегиональные маршруты, роботизированные зоны ближе к Москве и связка с конкретными заданиями кампании остаются дальнейшей работой. Наличие моделей на ПК не означает их доступность в этом checkout.

## Проверка

Сервер из корня: `python3 -m http.server 8080 --bind 127.0.0.1`. Затем `TERRA_TEST_URL=http://127.0.0.1:8080/play/ python3 tests/sewers.py`. Нужны Python Playwright и Chromium/Chrome. Тест использует чистый профиль и телепортацию тестового персонажа для проверки переходов; это не полное боевое прохождение и не тест физического телефона. Проверяется вход/выход, проходимость центров соединений, насосы, карта, сохранение/перезагрузка и повторный вход.

`play/ui/sewers.js` содержит читаемый модуль. `scripts/apply-sewer-bridge.py` воспроизводит маленький мост к существующему генератору из точного HTML main; он не адаптируется к неизвестной сборке молча. При следующей сборке оригинальных исходников мост необходимо перенести в исходный экспорт API.
