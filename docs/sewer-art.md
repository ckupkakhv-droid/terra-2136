# Арт канализации: мутант «Рафаэль»

Ассет врага или NPC для слоя коллекторов (PR #10, план из #9). Лаборатория (`lab_kit.glb`) будет в следующем PR.

## Файлы

- `play/assets/sewer/mutant.glb`: модель, риг и 10 клипов.
- `play/assets/sewer/manifest.json`: sha256, размер, высота, pivot, клипы, лицензии.
- `play/assets/sewer/CREDITS.md`, `LICENSE_Quaternius_*.txt`: источники и лицензии.
- `play/assets/sewer/preview.html`: превью с переключением клипов. Запуск: `cd play && python3 -m http.server`, затем открыть `/assets/sewer/preview.html`. three r160 грузится с jsDelivr.
- `tools/art/sewer_mutant/`: генераторы: `tex.py` делает текстуры, `build.py` делает модель, клипы и запекает атлас в Blender 4.2, `build.sh` собирает всё целиком.
- `docs/art/sewer/*.jpg`: рендеры, лист клипов, атлас, кадр из игры.

## Параметры

| | |
|---|---|
| Треугольники | 10 452 (лимит 12 000) |
| Кости | 53 (лимит 60), до 4 влияний на вершину |
| Меши / материалы | 1 skinned mesh, 1 материал (doubleSided) |
| Текстуры | атлас baseColor 1024² + normal 512², WebP |
| Сжатие | EXT_meshopt_compression + KHR_mesh_quantization |
| Размер | 685 468 байт (лимит 1,2 МБ) |
| Единицы и оси | метры, +Y вверх, лицом к +Z, pivot на полу между стопами |
| Высота | 1,82 м в bind-pose; в таблицу высот `Ke` предлагаем 2.0 |

## Клипы

| Клип | Длительность, с | Повтор | Источник |
|---|---|---|---|
| idle | 1,67 | loop | UAL1 Sword_Idle (стойка с саями) |
| walk | 1,33 | loop | UAL1 Walk_Loop |
| run | 0,92 | loop | UAL1 Jog_Fwd_Loop |
| attack | 1,50 | once | UAL1 Sword_Attack |
| attack2 | 1,00 | once | UAL1 Punch_Cross (тычок саем) |
| hit | 0,33 | once | UAL1 Hit_Chest |
| death | 2,33 | once, clamp | UAL1 Death01 |
| crawl | 2,00 | loop | UAL1 Crouch_Fwd_Loop (пригнувшись, для низких тоннелей) |
| scream | 1,58 | once | своя: стойка, голова и грудь запрокидываются, руки в стороны, дрожь головы |
| emerge | 2,00 | once* | своя: таз поднимается из-под воды с −1,1 м, затем присед и стойка |

\* В one-shot regex загрузчика `Ke` (`death|attack|attack2|punch|hit|shoot|roll|pickup|scream|charge`) нет `emerge`, поэтому этот клип по умолчанию зациклен. Codex при запуске ставит ему `setLoop(THREE.LoopOnce)` и `clampWhenFinished=true`. Пока таз ниже 0 (первые ~1,3 с), модель под полом: это задумано для выхода из воды в лотке.

## Подключение (делает Codex, без правки в этом PR)

```js
window.TERRA_ASSETS.sewer_mutant='url:assets/sewer/mutant.glb'
```

После этого модель доступна как `game.glb.sewer_mutant` (`Ke`). Если в таблицу высот добавить `sewer_mutant:2.0`, мутант станет чуть выше героя. Без записи его рост 1,8 м.

## Проверка

- Лист клипов `docs/art/sewer/03_clips.jpg`: 10 клипов по 3 кадра (15/45/80 %). Саи остаются в кулаках во всех клипах. Ватник не проваливается в тело и панцирь.
- В игре (main 7b3a4f1, init-скрипт добавляет ключ в `TERRA_ASSETS`): `game.glb.sewer_mutant` загрузился, scale 0,987, все 10 клипов на месте, ошибок и предупреждений GLB нет. Кадр: `docs/art/sewer/05_ingame.jpg`.
- `preview.html` открывается, все клипы переключаются.

## Известные ограничения

- Игра принудительно ставит roughness 1 и metalness 0, поэтому сверху и в темноте мутант выходит темнее, чем на рендерах. Хорошо читаются красная повязка и саи.
- Надпись на нашивке на атласе мелкая (~40 px). Её видно на крупных планах, в игре сверху её не прочитать.
- Ватник надет поверх панциря, сзади видны только щитки в прорехе. Так было в принятом концепте v2.
- Анимации взяты из общей человеческой библиотеки: походка человеческая, хвоста и челюсти нет.
- `crawl` — это ходьба пригнувшись, а не ползание на четвереньках.
