# Арт канализации: мутант «Рафаэль»

Ассет врага или NPC для слоя коллекторов (PR #10, план из #9). Лаборатория — `lab_kit.glb`, раздел ниже.

## Файлы

- `play/assets/sewer/mutant.glb`: модель, риг и 10 клипов.
- `play/assets/sewer/manifest.json`: sha256, размер, высота, pivot, клипы, лицензии.
- `play/assets/sewer/CREDITS.md`, `LICENSE_Quaternius_*.txt`: источники и лицензии.
- `play/assets/sewer/preview.html`: превью с переключением клипов. Запуск: `cd play && python3 -m http.server`, затем открыть `/assets/sewer/preview.html`. three r160 грузится с jsDelivr.
- `tools/art/sewer_mutant/`: генераторы: `tex.py` делает текстуры, `build.py` делает модель, клипы и запекает атлас в Blender 4.2, `build.sh` собирает всё целиком.
- `docs/art/sewer/*.jpg`: рендеры, лист клипов, атлас, кадр из игры.

## Параметры

| | |

| Высота | 1,82 м в bind-pose; в таблицу высот `Ke` предлагаем 2.0 |

Codex при запуске ставит ему `setLoop(THREE.LoopOnce)` и `clampWhenFinished=true`. Пока таз ниже 0 (первые ~1,3 с), модель под полом: это задумано для выхода из воды в лотке.

## Подключение (делает Codex, без правки в этом PR)

```js
window.TERRA_ASSETS.sewer_mutant='url:assets/sewer/mutant.glb'
```

После этого модель доступна как `game.glb.sewer_mutant` (`Ke`). Если в таблицу высот добавить `sewer_mutant:2.0`, мутант станет чуть выше героя. Без записи его рост 1,8 м.

## Проверка

- Лист клипов `docs/art/sewer/03_clips.jpg`: 10 клипов по 3 кадра (15/45/80 %). Саи остаются в кулаках во всех клипах. Ватник не проваливается в тело и панцирь.
- В игре (main 7b3a4f1, init-скрипт добавляет ключ в `TERRA_ASSETS`): `game.glb.sewer_mutant` загрузился, scale 0,987, все 10 клипов на месте, ошибок и предупреждений GLB нет. Кадр: `docs/art/sewer/05_ingame.jpg`.
- `preview.html` открывается, все клипы переключаются.

## Известные ограничения

- Игра принудительно ставит roughness 1 и metalness 0, поэтому сверху и в темноте мутант выходит темнее, чем на рендерах. Хорошо читаются красная повязка и саи.
- Надпись на нашивке на атласе мелкая (~40 px). Её видно на крупных планах, в игре сверху её не прочитать.
- Ватник надет поверх панциря, сзади видны только щитки в прорехе. Так было в принятом концепте v2.
- Анимации взяты из общей человеческой библиотеки: походка человеческая, хвоста и челюсти нет.
- `crawl` — это ходьба пригнувшись, а не ползание на четвереньках.

## Как подключить (делает Codex)

```js
window.TERRA_ASSETS.sewer_lab='url:assets/sewer/lab/lab_kit.glb'   // тот же загрузчик url:, что у mutant
// после загрузки:
const kit=game.glb.sewer_lab.src;                         // исходная сцена; make() не использовать — Ke масштабирует по высоте
const vat=kit.getObjectByName('vat').clone(); vat.position.set(x,0,z); vat.rotation.y=a; scene.add(vat);
// стены: в sewers.js стена 0,4 м стоит по центру границы комнаты, поэтому лицо модуля — на 0,2 м внутрь:
//   западная граница: put('vault_4m', ox+0.2, z, +Math.PI/2); восточная: put(..., ox+16-0.2, z, -Math.PI/2)
// гермодверь: bulkhead.updateMatrixWorld(); door.position.copy(bulkhead.localToWorld(new THREE.Vector3(-1.17,0,0)));
//   door.rotation.y = bulkhead.rotation.y + angle;  angle 0 — закрыта, −1.6…−1.9 — открыта в комнату
// лампа: позиция на стене, y≈2.6; свет — PointLight 0xffb870 в точке lamp.localToWorld(0,-0.15,0.32)
```

- `Ke` для этой сцены делает `frustumCulled=false` у всех мешей. У клонов набора лучше вернуть `true`, иначе рисуется вся лаборатория даже за кадром.
- Свечение (колбы, наросты, лампы) — emissive, на него не влияет roughness 1. Самой сцене нужны 2–4 PointLight (лампы, колбы), иначе в тёмном коллекторе остаются только светящиеся части.
- Коллайдеры не входят в glb: для стен — те же `col()` по 4 м, для колб — круг r 0,5, стол — 1,8×0,8, ящик — 0,8×0,6.

## Известные ограничения

- Камера игры смотрит сверху: таблички на стенах вертикальные и в игре почти не читаются. Сверху видны крышки ящиков (жёлтая этикетка), кольца на колбах, шляпки наростов и красный кирпич.
- Свод срезан на 3,4 м (высота стен в #10), полного кирпичного свода как в концепте нет — он закрыл бы героя.
- Пузыри в колбе почти сливаются с жидкостью; образца внутри нет.
