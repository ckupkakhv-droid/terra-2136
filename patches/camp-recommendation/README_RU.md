# Terra: рекомендация свободного работника

Статус: изолированный локальный кандидат. Не опубликован и не объединён с недоступным актуальным исходным репозиторием. Это не подтверждённый игровой выпуск.

## Что изменено

В существующем разделе жителей, после выбора задания «Вода», «Дерево» или «Стройка», добавляется небольшая карточка:

- Имя лучшего доступного работника по действующей формуле эффективности: навыки, нужды, мораль, черты и лагерные коэффициенты.
- Цена самого назначения: 0 ресурсов. Это не обещание бесплатного строительства или отсутствия обычного расхода еды и воды.
- Кнопка «Назначить: имя» с минимальной высотой 48 CSS px и переносом длинного имени.
- Свёрнутый список причин, почему другие жители недоступны.

Подбор только читает данные. Он использует действующий residentOrderReason и не забирает напарника, курьера, раненого, отдыхающего, переносчика груза или занятого работника. При нажатии передаёт конкретного показанного человека в существующий quickAssign. Сохраняются прежние проверки повторного нажатия, ухода из меню, смены игрока, сеанса записи и неопределённого результата сохранения. Новый формат сохранения и зависимости не добавлены. Ресурсы, модели, лицензии и поздние игровые механики не заменяются.

## Воспроизведение отдельного HTML

Нужны уже имеющиеся Python 3 и Node.js. Установки пакетов не требуется.

Из родительской папки, где лежат исходный HTML и папка патча:

    python terra-camp-recommendation-patch-20261104/apply_patch.py terra-scout-class-20261104.html terra-camp-recommendation-patch-20261104/terra-camp-recommendation-candidate.html
    python terra-camp-recommendation-patch-20261104/verify_patch.py terra-scout-class-20261104.html terra-camp-recommendation-patch-20261104/terra-camp-recommendation-candidate.html
    node --test terra-camp-recommendation-patch-20261104/test_model.mjs terra-camp-recommendation-patch-20261104/test_native_handlers.mjs terra-camp-recommendation-patch-20261104/test_render.mjs

Выходной файл должен отсутствовать. Исходный HTML в небольшом архиве патча не дублируется. Проверка test_native_handlers.mjs ожидает его на один уровень выше папки патча. Базовые тесты модели и DOM-контракта отдельно запускаются без исходного HTML.

Не заменять src/campui_settlers.js или src/camp/resident-orders.js историческими копиями. Не переносить минифицированные имена в исходники.

## Непроверенное и точный блокер

Chromium был запущен один раз с включённой песочницей. ОС завершила процесс до загрузки страницы: socket() failed: Operation not permitted. Дополнительно crashpad сообщил отсутствие каталога базы. Защита не отключалась, обходы и повторные запуски не выполнялись.

Поэтому браузер, WebGL, реальные кадры, физический телефон, портретная/альбомная раскладка и экспорт → импорт → продолжение не подтверждены. Скриншоты игрового результата отсутствуют. Полного актуального checkout нет; совместимость с ним требует интеграции по инструкции выше. Сетевые зависимости исходной игры отдельно не аудировались; патч новых не добавляет.
